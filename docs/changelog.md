# Changelog

## Version 4.2

- Startseite mit klarer Nutzerführung
- Module finden mit Kachel- und Listenansicht
- Modulprofile mit Entscheidungskarte
- Planung von Einzelstunden und Verläufen
- automatische Dokumentation in drei Varianten
- Dokumentation ohne interne Kürzel und ohne Zeiten
- empfohlene und häufig genutzte Module
- Geronto-Modus und Akut-Modus
- Handbuch & Grundlagen mit Suche, Schnellzugriffen, Kurzstruktur und Zurück-Funktion
- erweiterte Druckfunktionen
- Aufteilung der Einzeldatei in HTML, CSS, JavaScript und JSON für GitHub Pages
- Handbuch-Suche mit zyklischer Navigation und Fundstellenzähler
- Planungsempfehlungen reagieren sofort auf Änderungen der Wirkdimension
- Wirkungsverlauf wird aus anfänglichem Fokus und gewählten Modulbausteinen abgeleitet
- Weitere Wirkdimensionen können im Modulpicker gezielt ergänzt werden
- Planungsannahmen und tatsächlich beobachtete Dokumentationsinhalte sind getrennt
- neue Schnellstart-Stunden übernehmen keine vorgetäuschten Beobachtungen oder Wirkungen
- setting- und wirkdimensionsbezogene Planungstexte werden nur noch als übernehmbare Vorschläge angezeigt
- einheitliche sichtbare Versionierung HTML 4.2 / Karte 4.2
